# Language packs

- Packs live in `src/main/resources/translations/`. Keys are decimal indexes (`"459"`).
- **English** (`english.json`) is the complete set and the runtime fallback.
- `_implementedLanguages.json` lists `{index: "Name"}`. A pack is offered only if `translations/<name>.json` exists (`English` → `english.json`).
- UI call sites use `Language.get().get(LangKey.HP, hp, pct)` (or a `TextKey` without args). Mode changes and pause go through `GameCommandBus` (`LoadMode`, `TogglePause`); `ScndGenLegends.loadMode` stays the apply site.
- C++ HD uses `Language::get()[LangKey::Hp]` / `Language::get()["459"]` for lookup, and `.get(key, args…)` for `{0}` templates.
- Story dialogue uses `StoryKey.Sn_mm` (player-facing scene n, line mm in playback order).
- Tutorial slides use `TutorialKey` grouped by chapter (`INTRO_`, `HUD_`, `CM_`, `FURY_`, `AB_`, `ATTACKS_`). Chapter titles and shortcut chrome stay on `LangKey`.
- Templates use `{0}`, `{1}` placeholders. Apostrophes are literal (not `MessageFormat` quotes).
- After `setLanguage`, registered locale listeners refresh cached labels (menu, achievements, stage names, character blurbs, tutorial, the current story line, and in-match move HUD arrays).
- Story steps store `TextKey`s and resolve text when shown, so a language change updates the active line. Do not splice suffixes in Java; put the full line in the pack.
- Vs-brags use `BragKey.SPEAKER_VS_OPPONENT` (`CharacterEnum` index order). Move names use `MoveKey.CHAR_P*` / `_C*` / `_S*` (one key per slot even when English repeats). Resolve at display; keep English in `english.json`. Do not invent a second language pack.
- Do not splice sentences across keys. One key per sentence.
