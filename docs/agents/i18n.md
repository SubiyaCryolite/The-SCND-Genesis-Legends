# Language packs

- Packs live in `src/main/resources/translations/`. Keys are decimal indexes (`"459"`).
- **English** (`english.json`) is the complete set and the runtime fallback.
- `_implementedLanguages.json` lists `{index: "Name"}`. A pack is offered only if `translations/<name>.json` exists (`English` → `english.json`).
- UI call sites use `Language.get().get(LangKey.HP, hp, pct)` (or a `TextKey` without args).
- Story dialogue uses `StoryKey.Sn_mm` (player-facing scene n, line mm in playback order).
- Tutorial slides use `TutorialKey` grouped by chapter (`INTRO_`, `HUD_`, `CM_`, `FURY_`, `AB_`, `ATTACKS_`). Chapter titles and shortcut chrome stay on `LangKey`.
- Templates use `{0}`, `{1}` placeholders. Apostrophes are literal (not `MessageFormat` quotes).
- After `setLanguage`, registered locale listeners refresh cached labels (menu, achievements, stage names, character blurbs).
- Do not splice sentences across keys. One key per sentence.
